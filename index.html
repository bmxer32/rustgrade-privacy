Политика конфиденциальности — RustGrade

Дата вступления в силу: 10 августа 2026 г.

1. Общие сведения

RustGrade («Приложение») — мобильный симулятор апгрейда скинов Rust. Приложение бесплатно и предназначено исключительно для развлекательных целей. Никакие реальные предметы или валюта не разыгрываются и не обмениваются.

2. Какие данные мы собираем

Приложение может собирать следующие данные:

  • Данные аккаунта Google — адрес электронной почты и отображаемое имя при авторизации через Google Sign-In (используется для синхронизации прогресса).
  • Данные об использовании — анонимная аналитика Firebase (статистика запусков, ошибки приложения).
  • Рекламный идентификатор — используется Yandex Mobile Ads SDK для показа рекламы с вознаграждением.

3. Как мы используем данные

  • Синхронизация игрового прогресса между устройствами.
  • Показ рекламы с вознаграждением (Яндекс РСЯ).
  • Улучшение стабильности приложения (Firebase Crashlytics).

4. Передача данных третьим лицам

Мы не продаём и не передаём персональные данные третьим лицам, за исключением:

  • Google Firebase — для аутентификации и хранения прогресса.
  • Yandex Mobile Ads — для показа рекламы.

5. Хранение данных

Игровой прогресс хранится локально на устройстве и в облаке Firebase. Данные аккаунта хранятся до тех пор, пока пользователь не удалит аккаунт или приложение.

6. Права пользователя

Вы можете в любой момент:

  • Выйти из аккаунта Google в приложении.
  • Удалить приложение и все локальные данные.
  • Запросить удаление облачных данных, написав на email ниже.

7. Дети

Приложение не предназначено для детей младше 16 лет. Мы сознательно не собираем данные несовершеннолетних.
